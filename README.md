# Laboratório de estilos

Estilos visuais de animação feitos em código, testados no nosso formato (TikTok 9:16, pt-BR, render na nuvem só com
CPU). Todos contam a mesma cena de 8 s; veja `galeria.jpg` e `CATALOGO.md`.

```bash
node motor/render.mjs estilos/sitcom/teste video 4      # refaz o vídeo de um estilo
python3 -I ferramentas/galeria.py                        # refaz pôsteres, galeria e catálogo
```

Fontes dos estilos e licenças: `docs/FONTES.md`. Como portar um estilo: `docs/PORTAR_ESTILO.md`.
